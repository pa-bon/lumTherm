# lumTherm
A software for analysis of luminescent thermometry.

Luminescent thermometry is one of the possibilities for optical redout of the temperature. It works by exploring *T*-dependent emission spectra of luminescent species. In particular, a thermometric parameter monitoring a change in ratio of emission intensities in two different parts of the spectrum is often used. This software aims to facilitate finding the optimal wavelengths, for which the ratio should be calculated to achieve the highest sensitivity.  
**lumTherm** is based on a brute-force approach in which the ratios between all pairs of wavelengths are calculated for all temperatures. Then, the graphical interface based on sensitivity heatmaps will help the user in finding the optimal ones.
